# Jersey Baju - Frontend

Frontend application for the Jersey Baju platform. Built with React and React Router v7.

## 🚀 Getting Started

### 📦 Installation
```bash
npm install
```

### ⚡ Development
```bash
npm run dev
```

### 🔨 Build
```bash
npm run build
```

## 🌐 Tech Stack
- ⚛️ **React**
- 🔀 **React Router v7**
- 🧠 **TypeScript**
- 🎨 **Tailwind CSS**
- 🧩 **Modular Architecture**
